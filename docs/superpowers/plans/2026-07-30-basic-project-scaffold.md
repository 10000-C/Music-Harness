# Basic Project Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the approved pnpm Monorepo development scaffold with strict TypeScript contracts, linting, formatting, tests, and unified verification commands.

**Architecture:** The root owns toolchain configuration and orchestration. `packages/contracts` is an environment-neutral shared package; `apps/workstation` and `apps/agent` consume it through workspace dependencies but contain no application startup code. Empty future implementation directories are retained with `.gitkeep` files.

**Tech Stack:** Node.js 24.18.1, pnpm 9.15.9, TypeScript, ESLint flat config, typescript-eslint, Prettier, Vitest.

## Global Constraints

- Use a pnpm Monorepo rooted at the repository root.
- Enable strict TypeScript plus `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noImplicitOverride`, `noFallthroughCasesInSwitch`, `useUnknownInCatchVariables`, `verbatimModuleSyntax`, and `isolatedModules`.
- Keep `packages/contracts` independent of Node and DOM runtime APIs.
- Do not install Electron, React, Strands, openDAW, MCP SDK, SQLite/LibSQL, Vite, or packaging dependencies.
- Do not add BrowserWindow, application entry points, development servers, or business placeholders.
- Preserve empty future directories with `.gitkeep` only.
- Commit `pnpm-lock.yaml`.
- Final verification must include `pnpm install --frozen-lockfile`, `pnpm check`, dependency inspection, secret scan, and a clean Git worktree.

## File Map

### Root configuration

- `package.json`: private workspace metadata, fixed package manager, Node engine, and unified scripts.
- `pnpm-workspace.yaml`: declares `apps/*` and `packages/*` workspaces.
- `pnpm-lock.yaml`: reproducible dependency graph generated by pnpm.
- `.node-version`: fixes Node.js 24.18.1.
- `.npmrc`: exact dependency saves, strict peers, and workspace linking.
- `tsconfig.base.json`: shared strict compiler policy.
- `tsconfig.json`: strict root project for root TypeScript configuration files.
- `eslint.config.js`: flat ESLint configuration for TypeScript source and tests.
- `prettier.config.mjs`: formatting policy.
- `.prettierignore`: excludes existing documentation and generated/runtime directories from bulk formatting.
- `vitest.config.ts`: declares Vitest 4 projects for workspace test discovery.
- `.gitignore`: ignores dependencies, generated output, runtime caches, databases, local environment files, and candidate runtime directories.

### Contracts package

- `packages/contracts/package.json`: environment-neutral shared package with source export and package-local scripts.
- `packages/contracts/tsconfig.json`: no-emit strict typecheck config.
- `packages/contracts/vitest.config.ts`: Node test runner configuration for pure data and helper tests.
- `packages/contracts/src/domain.ts`: branded identifiers, `Tick`, fixed track registry, `TickRange`, `TaskScope`, and runtime guards.
- `packages/contracts/src/index.ts`: public package export surface.
- `packages/contracts/src/domain.test.ts`: registry and scope guard tests.

### Application workspaces

- `apps/workstation/package.json`: private workspace depending on `@agent-music/contracts` through `workspace:*`.
- `apps/workstation/tsconfig.json`: Node-oriented placeholder typecheck boundary with no source implementation.
- `apps/workstation/src/main/.gitkeep`: future Electron Main boundary.
- `apps/workstation/src/renderer/.gitkeep`: future Renderer boundary; no DOM config yet.
- `apps/workstation/src/core/.gitkeep`: future Music Core boundary.
- `apps/agent/package.json`: private workspace depending on `@agent-music/contracts` through `workspace:*`.
- `apps/agent/tsconfig.json`: Node-oriented placeholder typecheck boundary with no source implementation.
- `apps/agent/src/.gitkeep`: future Agent Service boundary.
- `vendor/opendaw/.gitkeep`: reserved openDAW vendor boundary.

expect(TRACK_IDS).toEqual([
  'track.drums',
  'track.bass',
  'track.guitar',
  'track.keys',
  'track.strings',
  'track.winds',

expect(isTrackId('track.keys')).toBe(true);

expect(isTick(-1)).toBe(false);

expect(isTickRange({ startTick: 960, endTick: 960 })).toBe(false);
expect(isTaskScope({ type: 'wholeProject', trackIds: ['track.drums'] })).toBe(
  true,

expect(
  isTaskScope({
    type: 'timeRange',
    trackIds: ['track.guitar', 'track.keys'],
    startTick: 0,
    endTick: 3840,
  }),
).toBe(true);
expect(
  isTaskScope({
    type: 'timeRange',
    trackIds: ['track.guitar', 'track.vocals'],
    startTick: 0,
    endTick: 3840,
